# Notice — scope, marks, and exclusions

`LICENSE` contains the unmodified MIT text so that automated license detection
reads this repository correctly. This file explains what that grant covers.

## What the MIT grant covers

The original source code in this repository: the OREBOT Network contracts in
`contracts/`, and the application and package code in `apps/` and `packages/`,
to the extent each was authored for this project.

## What it does not cover

- **Third-party components.** OpenZeppelin, forge-std, npm dependencies, and
  protocol interfaces retain their own licenses. See
  [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
- **Files with a different SPDX header.** A file declaring another
  `SPDX-License-Identifier` is governed by the header it declares.
- **The OREBOT name, the ORE logo, and brand identity.** MIT covers code. It
  grants no right to the project name or marks, and implies no endorsement of a
  derivative.
- **Deployed contract addresses.** Forks of this code do not confer control of
  the live contracts on Base Mainnet, which remain governed by the OREBOT Safe
  multisig, or of any token supply.

## Audit output is analysis, not ownership

Documents where OREBOT Network reviews or screens a third-party project are
commentary about that project. They create no ownership of the reviewed code,
name, or assets, and they do not license us to reuse it. Where a report quotes
someone else's source, the quotation is for identification and review.
